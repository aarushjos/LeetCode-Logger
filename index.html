LeetCode Logger

LeetCode Logger is a Chrome extension designed to help users automatically track and organize their solved LeetCode problems in Google Sheets.

Purpose of the Application

The purpose of LeetCode Logger is to simplify progress tracking for users practicing coding problems on LeetCode. When a user solves a problem, the extension records relevant details (such as problem title, difficulty, date solved, and URL) and logs them into the user's connected Google Sheet.

How It Works

  • User installs the Chrome extension.
  • User signs in with their Google account.
  • User grants permission to access and edit a specific Google Sheet.
  • When a LeetCode problem is solved, the extension appends a new row to the sheet.

Google API Usage

This application uses the Google Sheets API to create and update spreadsheets in the user’s Google account. Access is limited strictly to the functionality required to log solved LeetCode problems. No unrelated data is accessed, stored, or shared.

Data Usage

LeetCode Logger only accesses Google account data necessary to write to the user’s selected Google Sheet. The application does not sell, share, or transfer user data to third parties.
